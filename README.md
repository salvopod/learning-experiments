# Learning Experiments

An unlisted, share-by-link GitHub Pages collection for learning prototypes, Sana assets, reusable prompts and code patterns.

## Recommended entry structure

Each substantial experiment gets its own folder containing a working page and its local assets. Reusable source examples live in `examples/` and prompt data lives in `prompts/`.

```text
experiment-name/
  index.html
  styles.css
  script.js
  assets/
  prompts/
    example.json
```

The original JSON remains available as a source file. The experiment page should also render its important fields as readable text, explaining the purpose, inputs, expected output and learning application.
