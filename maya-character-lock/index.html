Character Lock

A structured JSON specification designed to preserve one character’s identity across different AI-generated scenes, poses and environments.

Purpose

Reduce visual drift when generating the same character repeatedly.

Format

Reusable JSON prompt specification.

Useful for

Learning guides, scenarios, storyboards and character-led courses.

How it works

Separate what must remain fixed from what may change.

Locked identity

Age, facial proportions, eye colour, skin tone, hair and overall presence.

Style guidance

Photorealism, skin texture, lighting and unwanted visual treatments.

Flexible scene

Clothing, pose, expression and environment can change for each learning moment.

Learning takeaway

Consistency improves when the prompt treats identity as structured data—not as a description rewritten from memory each time.

This does not guarantee identical outputs. A reference image, fixed generation settings and deliberate review are still important.
